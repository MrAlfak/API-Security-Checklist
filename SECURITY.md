# Security Policy

## Supported Versions

Security fixes are applied to the latest maintained version of this project.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Include:
- Affected file or section
- Security impact
- Reproduction steps
- Suggested mitigation

## Security Review Principles

This project follows:
- OWASP API Security Top 10
- OWASP ASVS principles
- RFC 9700 OAuth 2.0 Security Best Current Practice
- RFC 8725 JSON Web Token Best Current Practice

## Disclosure

We aim to acknowledge reports quickly and coordinate fixes before public disclosure.
